# 🕵️ Détective Info — Microsite Fake News

Microsite pédagogique complet pour collégiens, sur la détection et la compréhension des fake news.

## 📁 Structure des fichiers

```
microsite-fakenews/
├── index.html         → Page d'accueil (quiz, statistiques, parcours, détecteur interactif)
├── sequence1.html     → Mission 01 : Le Piège (journal interactif, 5 indices à trouver)
├── sequence2.html     → Mission 02 : L'Émotion (à créer — voir ci-dessous)
├── sequence3.html     → Mission 03 : L'Enquête (à créer)
├── sequence4.html     → Mission 04 : Le Labo (à créer)
├── sequence5.html     → Mission 05 : Le Défi Final (à créer)
├── outils.html        → Boîte à outils & ressources (à créer)
└── README.md
```

## 🚀 Comment héberger gratuitement

### Option 1 — GitHub Pages (recommandé, GRATUIT)
1. Créer un compte sur github.com
2. Nouveau dépôt : "detectiveinfo" (cocher "Public")
3. Glisser-déposer tous les fichiers HTML dans le dépôt
4. Settings → Pages → Branch: main → Save
5. Ton site sera disponible sur : `https://TON-PSEUDO.github.io/detectiveinfo/`

### Option 2 — Netlify Drop (le plus simple)
1. Aller sur app.netlify.com/drop
2. Glisser-déposer le dossier entier
3. URL générée instantanément ! (ex: random-name-123.netlify.app)
4. Possibilité de personnaliser le nom

### Option 3 — Glitch.com
1. Créer un compte sur glitch.com
2. New Project → Import from GitHub ou coller le code
3. Support complet HTML/CSS/JS

## 📝 Pages à créer (suite du parcours)

### sequence2.html — L'Émotion
- Schéma interactif "Comment le cerveau traite une info émotionnelle"

### sequence3.html — L'Enquête
- Guide animé des outils : TinEye, Snopes, AFP Factuel, Décodex

- Checklist SIDIIEF interactive

### sequence4.html — Le Labo (activité en duo)
- Générateur de "squelette de fake news" (mad-libs pédagogique)

- Débriefing collectif

### sequence5.html — Le Défi Final
- Formulaire de soumission de projet (affiche ou lien vidéo)
- Galerie des projets d'élèves

### outils.html — Boîte à outils
- Fiche mémo SIDIIEF téléchargeable (PDF)

## 💡 Notes pédagogiques

- Chaque séquence = 1 bloc d'accroche + 1 activité interactive + 1 apport théorique + 1 mémo
- Le système de progression (barre + compteur d'indices) maintient la motivation
- Les activités en duo (séquence 4) permettent la médiation par les pairs
- Le projet final (séquence 5) ancre les apprentissages dans une production concrète
